下列各数列中，是等差数列的是
【答案】B
【解析】

单项选择题 · 4 分 ｜ 沪教版 · 选择性必修第一册 · 4.1 等差数列

思路：按"从第 2 项起，每一项与前一项的差都等于同一个常数"逐一检验。

解答：题中四个对象都是按一定顺序排列的一列数，都是数列，可分别记作 {an}，第一个数称为首项 a1

逐选项判定：

A．相邻两项之差依次为 1, 2, 4，不是同一常数。

B．5−2=8−5=11−8=3，差恒为 3，是首项 a1=2、公差 d=3 的等差数列。

C．差为 3, 5, 7。

D．差为 −2, 2 交替。

易错点：判断等差只看"差是否为同一常数"，与数列增减无关；D 中差正负交替，虽呈规律但不是等差数列。

2单项选择题4 分
已知三个数 4，x，12 成等差数列；又等差数列 {an} 满足 a1=4，a4=12。则 x 与公差 d 的值分别为
【答案】A
【解析】

单项选择题 · 4 分 ｜ 沪教版 · 选择性必修第一册 · 4.1 等差数列

思路：先用等差中项求 x，再用通项公式列方程求 d。

解答：由 4，x，12 成等差数列，得 x 是 4 与 12 的等差中项，即 x=4+122=8（等差中项唯一，等于前后两项的算术平均数），由 a4=a1+3d，得 12=4+3d，故 d=83，等差数列（arithmetic sequence）的定义要点有二：一是"从第 2 项起"，二是差"等于同一个常数"，即 an−an−1=d（n≥2），公差（common difference）通常记 d

错误选项辨析：

B．错在把 d 误当作 a4−a1。

C．错在把等差中项当作两项之和。

D．错在误用 a4=a1+4d。

易错点：an=a1+(n−1)d 中公差的个数是 n−1 而不是 n；等差中项是算术平均数，不是两项之和。

3单项选择题4 分
已知数列 {an} 的通项公式为 an=2n−3，下列说法正确的是
【答案】A
【解析】

单项选择题 · 4 分 ｜ 沪教版 · 选择性必修第一册 · 4.1 等差数列

思路：an=2n−3 是 n 的一次函数，先验证定义，再看 n=1 是否适用。

解答：an−an−1=(2n−3)−(2n−5)=2（与 n 无关），且 n≥2 时恒成立，故 {an} 是等差数列；a1=2×1−3=−1，即首项为 −1、公差为 2。一般地，若 an=pn+q（p，q 为常数），则 {an} 是等差数列，首项为 p+q、公差为 p。判定等差数列的方法：①定义法——验证 an−an−1（n≥2）为与 n 无关的常数；②通项法——验证 an 是 n 的一次函数；③中项法——验证 2an=an−1+an+1（n≥2）。由通项公式求出的式子当 n=1 时也成立（a1=−1=2×1−3），故它对一切正整数 n 都成立，D 错。

易错点："一次函数"与"不是等差数列"没有必然联系，恰好相反，一次函数型通项（d≠0）保证等差。

单项选择题 · 4 分 ｜ 沪教版 · 选择性必修第一册 · 4.1 等差数列

思路：逐项辨析四个命题的真假。

逐选项判定：

A．正确，公差可正、可负、也可为 0：d>0 时严格递增，d<0 时严格递减，d=0 时为常数列。

B．正确，等差中项唯一，就是 a+b2（这与等比中项同号时可能有两个形成对比）。

C．错误，该数列相邻两项之差轮流为 0 与 1，不是"同一个常数"，仅由前两项之差为 0 就断定公差为 0，是只验证前几项的错误做法，判断时必须对一切 n≥2 都有 an−an−1=d。

D．正确，Sn=a1+a2+⋯+an=∑i=1nai 称为前 n 项和，且 S1=a1。

易错点：验证有限个相邻差相等不能说明整个数列是等差数列；"同一个常数"意味着与 n 无关。

5单项选择题4 分
在等差数列 {an} 中，a1=−4，a10=14，则 S10=
【答案】A
【解析】

单项选择题 · 4 分 ｜ 沪教版 · 选择性必修第一册 · 4.1 等差数列

思路：已知 a1 与 an，选用 Sn=n(a1+an)2（倒序相加所得）。

解答：S10=10×(−4+14)2=50，故选 A。另一形式：先求 d=14−(−4)9=2，再用 Sn=na1+n(n−1)2d=−40+45×2=50，一致。其推导要点：把 Sn 正序、倒序各写一次相加，Sn=a1+(a1+d)+⋯+[a1+(n−1)d] 与 Sn=an+(an−d)+⋯+[an−(n−1)d] 对应项之和均为 a1+an，共 n 对，故 2Sn=n(a1+an)。这源于高斯配对法：求 1+2+⋯+100 时与倒序式相加，每对和为 101，共 100 对，得 101×1002=5050。B 45 是误把项数当作 9；C 100 是漏除以 2；D 90 是把 n(n−1)2d 误乘成 n(n−1)d 后又算错首项。

易错点：两个求和公式各有适用条件——已知 a1 与 an 用 n(a1+an)2，已知 a1 与 d 用 na1+n(n−1)2d。

杨辉"圭垛"问题：把草束堆成圭垛，顶层 1 束，从第 2 层起每层比上一层多 2 束，各层束数依次构成等差数列 {an}，且 a4=7，前 n 项和为 Sn。下列结论正确的是
【答案】ACD
【解析】

多项选择题 · 6 分 ｜ 沪教版 · 选择性必修第一册 · 4.1 等差数列

思路：由 a4=7 与"每层多 2 束"定出基本量，再逐项判定。

解答：由题意 a1=1，d=2，故 an=2n−1，a4=2×4−1=7 与条件一致。

逐选项判定：

A．对：由下标和相等性质 a1+a7=2a4=14，故 S7=7(a1+a7)2=7a4=49，这种"下标和相等"的用法可避免求 a1 与 d。

B．错：n(n+1)2 是 1+2+⋯+n（公差为 1）的和；本题 Sn=n(1+2n−1)2=n2，堆 n 层总束数为 n2。

C．对：Sn=n2 是 n 的二次函数（且常数项为 0），可用配方法研究最值。

D．对：an=2n−1>0 对一切正整数成立，Sn 随 n 增大而增大，无最大值（公差 d>0 时 Sn 无最大值；d<0 时才可能在 an 由正变负处取最大）。

易错点：杨辉"圭垛"、《九章算术》"竹九节"等都是把实际问题化为等差数列求和的典型模型；本题易把堆垛总数误记为 n(n+1)2，须先确认公差。
